Talk at EthCC 2026 on the design of CMTAT, the CMTA security token framework, on EVM.

- One codebase for several use cases (equities, debt, stablecoin) and jurisdictions: flexible, modular and integrated with Ethereum standards (ERC)
- Built in Solidity on top of ERC-20 and OpenZeppelin libraries
- Security process: audits for major releases, static analysis and AI audit tools for minor releases
- Path to privacy: Aztec and Zama FHE versions
